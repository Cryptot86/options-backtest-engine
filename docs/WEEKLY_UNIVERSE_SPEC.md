*Adopted as PROCESS 2026-08-02. Receipts: 6-mo RS-vs-SPY at golden-cross entry,

RS (relative strength vs market, = IBD's RS Rating), NOT RSI (the oscillator).*

## The weekly ritual (~15 min, Sunday; IBD/MarketSurge or TradingView screener)
1. **Universe**: liquid US stocks — mcap > $1B, avg daily $ volume > $10M.
   (Or simply: IBD's screened universe.)
2. **Rank**: 6-12 mo return vs SPY. Keep top ~50. (IBD shortcut: RS Rating ≥ 80.)
3. **Segments**: group the top 50 by industry. **THEME = any industry holding
   3+ slots** (this is the mechanical EV/chips/memory detector — it fires weeks
   before the narrative). IBD shortcut: Industry Group Rank top quartile AND
   rising.
4. **Watchlist** = per active theme, the top 2-3 RS names + core mega-caps +
   current holdings + the turnaround shelf (beaten-down mega-caps you already
   follow — the META-2023 class stays watchable BECAUSE RS never vetoes).
5. **Entry**: the 10x100 cross (5-bar window) decides WHEN — always and only.
   The list is never bought directly. No cross, no trade, however hot the theme.

## When several theme names cross together (AVGO + NVDA same week)
Priority stack — mostly rules that ALREADY exist:
1. **Correlation blocks fire first** (guardrail #3: 0.85 same-sector) — the
   system already refuses to hold near-duplicates; expect 1-2 slots per theme,
   not 5. This answers "which ones" by subtraction.
2. **Tiebreak among simultaneous valid crosses: highest RS wins** (leader-first
   — the 4x gradient is the receipt; forward-journal this tiebreak).
3. **TSP sizing as normal** — hot high-ATR theme names auto-size smaller.
4. Never widen a correlation block or size up to "fit the theme in." The theme
   is served by 1-2 leaders; the rest is concentration wearing a costume.
